# 数据与安全边界

自托管服务不向项目作者回传资料，不添加遥测。飞书、GitHub和Coding工具的上游模型是独立第三方；它们各自的数据处理规则仍适用。

| 内容 | 保存或处理位置 |
|---|---|
| 飞书原文、作者、修订与撤回状态 | 团队自有服务器SQLite；摘要电脑处理选定来源 |
| 六字段摘要与明确选择的Agent记忆 | 团队GitHub私有库及成员缓存、服务器只读镜像 |
| 模型请求 | 成员选择的Codex/Claude模型服务，消耗本人额度 |
| 模型认证 | 成员本机；Codex整理器临时复制必要登录文件、结束清理；不复制到服务器 |
| 网页账号 | 自有服务器加盐密码哈希和服务端会话；初始领取文件须私下交付 |
| 备份 | 管理员选择的位置；加密档案与解密密钥应分离保存 |

所有有效成员可读团队共享内容。GitHub写权限由GitHub控制，网页账号不能授予GitHub权限；成员停用服务不能回收已克隆资料。部署工具不会远程撤销GitHub协作者，管理员必须完成此操作。

HTTPS、Cookie、Origin/CSRF和限速保护用于本项目网页；不是互联网安全认证。应用只监听loopback，公网由Nginx代理。资料、生成摘要和来源命令始终视为数据，不构成执行指令。摘要适配器缺少必需安全功能时禁用，不能放开工具绕过。

已撤回来源的当前摘要失效不保证Git历史、旧克隆或备份彻底擦除。列表和同步存在延迟。多机摘要接管、附件正文理解、细粒度项目权限、SSO及完全离线模型均不属于首版承诺。

发现问题时请不要在公开Issue粘贴密钥或私人资料。先停止受影响入口、保留私有诊断并轮换相关凭证；脱敏后报告软件版本、触发条件与影响范围。项目目前未设公开的私密漏洞接收邮箱，不虚构联系方式。
