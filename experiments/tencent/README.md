# 腾讯方案隔离对照

候选：TencentCloud/TencentDB-Agent-Memory。固定版本：ecc01a545da0b2ac6cae2f0f0af0d39d41469793，分支feat/server_team。
这是团队Memory Hub路线，不能拿旧main分支的个人记忆插件文档代替安装说明。

先完成本项目真实双人共享，再启用隔离对照环境。使用独立数据库、端口、身份和模型配置，不修改生产客户端。
官方安装涉及memory-core、memory-hub、proxy及模型参数，启动面板不等于团队权限和检索验收。
只导入双方确认可共享的脱敏资料，禁止自动导入私人聊天历史。

固定10个问题：当前决策、各自主张、原始来源、仍未验证假设、历史版本、已替代判断、撤回内容、私有内容、跨工具复用、缺失依据。
逐项记录命中、来源正确性、版本/作者、越权、撤回行为、耗时及模型用量。缺失能力记为unsupported，不临时重造以粉饰比较。
样例与比较脚本见本目录；结果状态必须区分NOT_RUN、BLOCKED、FAIL与PASS。
这组小样本只支持案例级结论，不支持整体产品优劣、长期效率或模型学习效果的声明。
